# evewibe.dev — Portfolio

Personal portfolio of **Aleksey Gryzlov**, .NET Backend Developer at Gazprom Neft.

## Stack

- React 19 + TypeScript 6
- Vite 8
- CSS Modules (no UI library)

## Sections

| Section | Description |
|---|---|
| Hero | Intro with photo |
| Skills & Stack | Tech grouped by category |
| Projects | Career Craft, Smart Anemia Scan, AdSe, CinemaDedaNyashik |
| Footer | Nav + socials |

## Dev

```bash
npm install
npm run dev      # localhost:5173
npm run build    # tsc + vite build
npm run lint
```
